# Business canvas — hypotheses, not validated results

ช่องทาง/ความสัมพันธ์: web + LINE หลังผูกบัญชี; onboarding ด้วยไฟล์ตัวอย่าง/หน่วยสินค้า. Partner API เป็น NOT_CONNECTED จนมีสิทธิ์.

รายได้/ต้นทุน: Subscription/pricing ยังเป็น hypothesis; ไม่มีหลักฐาน willingness-to-pay. Cloud serverless prototype workload estimate แยกใน cost-estimate.md; ประเมินต้นทุน onboarding/support/ตรวจ adapter เพิ่มก่อนตั้งราคา.

ทรัพยากร/กิจกรรม: deterministic engine, report adapters, effective-dated costs/rules, QA merchant samples, tenant security. Partners: merchant willing to share authorized samples; AWS/LINE/platform permissions are dependencies.
