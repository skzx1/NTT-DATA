# วิธีใช้ MarginSight

1. กดสมัครบัญชีใหม่ ยืนยันอีเมลใน Cognito แล้วเข้าสู่ระบบ ตั้งชื่อร้านและกด “สร้างร้านของฉัน” เพื่อเริ่มร้านส่วนตัวว่างได้ทันที; บัญชีที่มีร้านสาธิตเลือกปุ่มสร้างร้านส่วนตัวได้. หนึ่งร้านส่วนตัวต่อบัญชี.
2. นำเข้าสินค้า/ต้นทุนผ่าน CSV/XLSX เมื่อมีหลายร้อยรายการ. ไม่กรอกใหม่ทุกครั้งที่ขาย.
3. นำเข้าออเดอร์และรายการค่าบริการเป็นงานเบื้องหลังครั้งละ 1,000 แถว. ดู duplicate/error/conflict; source file ที่ PARTIAL ยังใช้คำนวณไม่ได้.
4. เปิดออเดอร์ กด “คำนวณ / ดูหลักฐาน” อ่านตารางเงินหักพร้อมประเภท/ยอด/หลักฐาน แล้วกด “ตรวจครบแล้ว ยืนยันค่าบริการ” เมื่อชุดครบ. หากข้อมูลออเดอร์หรือต้นทุนเปลี่ยนต้องเปิดหลักฐานใหม่; เงินหักที่นำเข้าเพิ่มจะเปิดสถานะให้ยืนยันใหม่. กฎ/version/program enrollment ใช้ประมาณการและ what-if; ไม่เดา rate จริงจากชื่อแพลตฟอร์ม.
5. ภาพรวมแสดงกำไรจากออเดอร์ข้อมูลครบ พร้อม coverage. ดูออเดอร์/หลักฐานเพื่อทราบ cost version, fees, source refs, calculation snapshot.
6. จำลองส่วนลด/ราคา และดู margin, fee ratio, TTR แยกฐาน. ข้อมูลต้นแบบรองรับ what-if ออเดอร์หนึ่งรายการสินค้า; ตะกร้าหลายสินค้าใช้งานคำนวณจริง/แบ่งค่าบริการได้ แต่ต้องเลือก scenario ที่ชัดก่อนจำลอง.
7. ผู้ช่วยไทยใช้ tools ของ engine เดียวกัน. หากโมเดลปิด/ผิด/timeout ใช้ deterministic fallback พร้อม reason.
8. บิลซื้อสร้าง OCR draft แล้วตรวจ SKU/จำนวนแพ็ก/ชิ้นต่อแพ็ก/ยอด/วันที่. อ่านไม่สำเร็จใช้ manual review; ไม่มี OCR สำเร็จปลอม.
9. กระทบยอดแยก actual vs estimate และส่งออก CSV/XLSX พร้อมสถานะ/ฐาน/สูตร. Item payout ไม่ใช่ bank settlement ทั้งหมด.
10. LINE ต้องมี channel credentials ใน Secrets Manager, ตั้ง webhook แล้วสร้าง LINK code จากเว็บ. ใช้ code ครั้งเดียวภายใน 5 นาที. ไม่มี credentials ให้แสดงยังไม่เชื่อม.

MOCK คือข้อมูลจำลองที่ทำงานผ่านระบบจริง; ไม่ใช่ live marketplace connection. กำไรที่แสดงไม่รวมค่าใช้จ่ายที่ยังไม่ได้บันทึก.

## ตรวจรับไฟล์ที่มีปัญหา

ไฟล์PARTIALยังไม่ใช้คำนวณและต้นทุนที่นำเข้าจากไฟล์นั้นยังไม่ active เปิดแถวผิด/ดาวน์โหลดต้นฉบับ เปรียบเทียบข้อมูลขัดแย้ง ระบุเหตุผลแล้วเลือกคงข้อมูลเดิมหรือใช้รายการใหม่ (เก็บrevisionเดิม) จากนั้นเลือก “ตรวจแล้ว รับเฉพาะแถวที่ถูกต้อง” ระบบเก็บแถวที่แยกออก/เหตุผล/ผู้ตรวจเพื่อaudit แถวที่ผิดไม่กลายเป็นรายการเงิน แก้CSVแล้วนำเข้าใหม่โดยคงtransactionIDsเดิม งานQUEUED/PROCESSINGที่ค้างส่งอีกครั้งได้โดยไม่เพิ่มยอดซ้ำ

publicMOCKpreviewเข้าได้โดยไม่ล็อกอิน คำนวณด้วยengineเดียวในbrowserแบบอ่านอย่างเดียว ส่วนอัปโหลด/ต้นทุน/ร้าน/ผู้ช่วยต้องล็อกอินและมีmembership. OCRตัวอย่าง1ภาพมีชื่อสินค้าและหน่วยผิด ต้องเลือกSKU/กรอกจำนวนและชิ้นต่อแพ็กตามบิลจริงเองก่อนยืนยัน

ร้านใหม่: เพิ่มสินค้ารายการเดียวที่ “สินค้าและต้นทุน” หรือโหลดแบบฟอร์มว่างจาก “นำเข้ารายงาน” กรอกสินค้า → ต้นทุนต่อหน่วยขาย → ออเดอร์ → รายการเงินหัก. ตรวจสิทธิ์ข้อมูล/คอลัมน์แล้วติ๊กยืนยันก่อนส่งแต่ละไฟล์. เมื่อข้อมูลยังไม่ครบระบบยังไม่แสดงกำไรที่ยืนยันแล้ว; เปิดหลักฐานเพื่อตรวจชุดค่าบริการก่อนยืนยัน. ยังต้องเตรียมไฟล์เป็นแบบMarginSightเอง ระบบไม่ได้ดึงข้อมูลแพลตฟอร์มโดยตรง.
